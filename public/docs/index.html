net.estudiosriva.ani.core Visión General y Arquitectura

El sistema ANI Index opera sobre una arquitectura serverless híbrida desplegada en Netlify, diseñada para evaluar trayectorias completas de cine y televisión sin costes de base de datos ni latencia bloqueante en el cliente.

01 · BATCH DIARIO (05:00 UTC)
GitHub Actions + IMDb TSV
Descarga title.ratings.tsv.gz y title.basics.tsv.gz, filtra movie, tvSeries y tvMiniSeries (≥300 votos) y publica imdb-ratings.json en la rama orphan data.
02 · CDN EDGE (24h CACHE)
jsDelivr Static Distribution
Frontend (IndexedDB 24h) y Netlify Functions (memoria) consumen el JSON minificado directamente desde cdn.jsdelivr.net sin disparar redeploys.
03 · TIEMPO REAL
TMDb API v3 + Wikidata SPARQL
Resuelve créditos de cine (movie_credits) y series (tv_credits), external_ids, taquilla, reseñas VADER y premios históricos CC0.
04 · CLIENTE & ON-THE-FLY
Seeds + LocalStorage + Cola
Consulta primero seeds precalculados y caché por rol; solo encola cálculo serverless para intérpretes o directores no registrados.

Pipeline Diario de IMDb (scripts/build-imdb-json.mjs)

Cada madrugada a las 05:00 UTC (cron: '0 5 * * *'), el workflow .github/workflows/update-imdb-ratings.yml ejecuta un streaming en dos pasadas de bajo consumo de memoria:

  • Pasada 1 (title.ratings.tsv.gz): Almacena en un Map los títulos con numVotes >= 300.
  • Pasada 2 (title.basics.tsv.gz): Cruza cada tconst candidato y conserva únicamente titleType ∈ {"movie", "tvSeries", "tvMiniSeries"} con isAdult !== "1".
  • Exclusiones estrictas de género en IMDb: Descarta cualquier título cuyo campo genres contenga Documentary, News, Talk-Show, Reality-TV o Game-Show, así como episodios individuales (tvEpisode), cortos (short) o videojuegos.
  • Salida: JSON minificado {"tt0468569":[9.0,2950000]} publicado mediante force-push a la rama data y distribuido vía jsDelivr.
https://cdn.jsdelivr.net/gh/DavidFerreiro-dev/ANI-Index@data/imdb-ratings.json

Capa en Tiempo Real de TMDb y Respaldo

La capa de TMDb actúa simultáneamente como fuente de metadatos visuales/estructurales y como respaldo inmediato en tiempo real: si un estreno reciente de cine o televisión todavía no figura en el corte diario de las 05:00 UTC de IMDb, el motor usa el rating de TMDb al 100%. Los umbrales de votos solo determinan elegibilidad; no suavizan ratings.

  • Películas: /person/{id}/movie_credits + /movie/{id} (incluye imdb_id, revenue, budget, belongs_to_collection).
  • Series y Miniseries: /person/{id}/tv_credits + /tv/{id}?append_to_response=external_ids (resuelve external_ids.imdb_id y type).

Aislamiento de Roles, Caché y Cálculo al Vuelo

Los perfiles de Actor y Director están estrictamente aislados tanto en los archivos seed como en el almacenamiento local del navegador (localStorage) y en las funciones serverless:

FacetaPrefijo / Clave de CachéEndpoint ServerlessVersión Activa
Actorsactor-merit-ranker:actor:{id}/api/actors/{id}26.4
Directorsactor-merit-ranker:director:{id}/api/directors/{id}"Director Scoring version 5.1"
Global Purgerani_algo_versionpurgeStaleAniCache()"actors-v26.4_directors-v5.1"

De este modo, un perfil dual (por ejemplo, Clint Eastwood o Ben Affleck) mantiene notas independientes para su faceta interpretativa y su faceta de dirección. Al abrir la ficha de una película o serie, la cola de concurrencia (max = 2) comprueba primero los JSON seed y después localStorage; únicamente los créditos no cacheados se calculan al vuelo.

net.estudiosriva.ani.actors.v26 Especificación — Actores v26

El modelo Actors v26 mantiene congeladas las fórmulas y pesos consolidados de la v25, ampliando el universo de obras evaluables a series de televisión y miniseries bajo filtros estrictos de participación.

PilarPeso BaseMecanismo Principal
Filmography Quality40%Ventana deslizante (6–8 obras), una entrega por saga en el Top 5 y peso 0.5× / 0.25× para las siguientes; ratings directos 60/40 IMDb+TMDb.
Awards Prestige30%Oscars, BAFTA, Cannes, Venecia, Berlín, Globos de Oro, SAG y Emmys (0.60× para TV), con freno asimétrico umbralado a 18 pts.
Commercial Impact10%Top 5 estrenos post-1980 (90% recaudación logarítmica ajustada por década + 10% ROI acotado 0.5×–10×, máx. 1/saga).
Critical Sentiment10%Análisis VADER sobre frases de reseñas que mencionan al actor o personaje (tope 89 si faltan reseñas).
Genre Versatility10%Familias de género distintas con order <= 3 y vote_average >= 6.5 (sobre 6 familias máx.).

Ponderación Directa (60/40 Cine · 75/25 TV), sin Suavizado por Votos

imdbWeight = (media_type === "tv") ? 0.75 : 0.60 Rating_Final = (r_imdb > 0) ? imdbWeight * r_imdb + (1 - imdbWeight) * r_tmdb : r_tmdb // Los votos solo aplican filtros de elegibilidad; no modifican el rating.

Mínimo de votos TMDb en cine VOTING_THRESHOLD = 50 (relajado en TV a TMDb >= 25 || IMDb >= 500); estos umbrales no aplican curvas ni priors al score.

Calidad de Filmografía (40%)

Las películas se agrupan con belongs_to_collection.id y, si falta, por raíz común del título. En el Top 5 de calidad solo entra 1 película por franquicia; las entregas posteriores pueden aportar consistencia con peso 0.5× para la segunda y 0.25× desde la tercera. El tamaño de ventana selectedCount depende de workCount:

if (workCount ∈ [3, 10]) → selectedCount = min(5, eligible.length) // Carrera corta else if (workCount <= 6) → selectedCount = eligible.length else if (workCount >= 14) → selectedCount = 8 else → round(6 + ((workCount - 6) * 2) / 8) // Pesos de facturación (billing order): // Estándar: order 0: 1.00 | order 1: 0.80 | order 2: 0.60 | order 3-5: 0.35 | minor: 0.10 // Carrera corta (3-10 obras): order 0: 1.35 | order 1: 1.05 | order 2: 0.65 | order 3-5: 0.15 | minor: 0.05 // Multiplicadores: +1.25× si director curado de prestigio | +1.15× si obra premiada en Wikidata q = Σ(roleWeight * franchiseWeight * directRating) / Σ(roleWeight * franchiseWeight) Normalización: [6.0 → 25, midpoint (6.5 | 6.40) → 55, max (7.8 | 7.45) → 100]

Bonus de trayectoria histórica, aplicado al resultado final tras max(scoreBaseCine, scoreConSeries): +1.0 con span de 15–19 años y destacados en 2 décadas; +2.5 con 20–29 años y 3 décadas; +3.5 con 30+ años y 4+ décadas. Destacado = rating directo ≥ 7.3 y billing order ≤ 2.

Reglas de Inclusión de Series, Tramos por Episodios y No Penalización (Actors v26.4)

  • Tipos admitidos y votos mínimos: tvSeries y tvMiniSeries con TMDb votes >= 25 o IMDb votes >= 500, resolviendo obligatoriamente external_ids.imdb_id para cruzar con IMDb al 75 % IMDb / 25 % TMDb.
  • Porcentaje de participación (excluyendo temporada 0 de especiales): participacion = (episode_count / regular_episodes) * 100.
  • Tramos de peso: < 35% descartada · 35–49% → 0.35 · 50–74% → 0.50 · 75–89% → 0.75 · 90–100% → 1.00 (papel protagonista pleno).
  • Regla de No Penalización: Se calcula scoreBaseCine (solo películas) y scoreConSeries (cine + series), estableciendo score = max(scoreBaseCine, scoreConSeries). Además, las series cuya nota directa sea inferior a la media cinematográfica del actor se ignoran en consistencia.
  • Exclusiones estrictas: Géneros TMDb 99 (Documentary), 10763 (News), 10764 (Reality), 10767 (Talk Show), 10770 (TV Movie); créditos no ficticios donde character empiece por Self, Himself, Herself, Themselves, Narrator, Host, Guest, Contestant o contenga archive footage / (voice); eventos de lucha libre y MMA (WWE, WWF, WrestleMania, Royal Rumble, UFC, etc.); recopilatorios y títulos sin votos suficientes.

Premios (30%), Taquilla (10%), Sentimiento (10%) y Versatilidad (10%)

// Awards Prestige (30%) Oscar Lead: 38 won / 10 nom | Oscar Supporting: 18 won / 6 nom Tier S (BAFTA, Cannes, Venecia, Berlín, Goya): Lead 24/8 | Supp 11/4.5 Tier A (Globos de Oro, SAG, Critics Choice, Emmy*0.6): Lead 10/4 | Supp 5/2 Tier B (Saturn, Sitges, Satellite, Gotham): decaimiento 0.60^k, tope 15 pts | Otros: +0.5 (tope 10 pts) AwardsScore = min(100, log(1 + points) * 100 / log(101)) // Piso mínimo 75 si ganó Oscar // Freno asimétrico umbralado: if (awards >= baseScore) → 0.70 * baseScore + 0.30 * awards else { excess = max(0, baseScore - awards - 18) brake = 0.15 * min(1, excess / 24) score = (1 - brake) * baseScore + brake * awards }

net.estudiosriva.ani.directors.v5 Especificación — Directores v5

El modelo Directors v5 conserva la arquitectura matemática de la v4 e integra las series y miniseries dirigidas bajo control estricto de episodios y límite de franquicia/serie.

PilarPesoComposición
Filmography Quality & Consistency40%70% Peak (Top 4 obras, máx. 1 por franquicia/serie) + 30% Consistencia (ventana 6–12, máx. 2 por franquicia), ratings directos 60/40.
Awards & Festivals Prestige25%Tier S (25/9), Tier A (12/5), Tier B (7/3) sobre dirección, mejor película/serie y guion.
Commercial Impact15%Top 3 largometrajes post-1980 (70% log gross + 30% ROI, 1.10× bonus original standalone).
Authorship & Versatility10%75% Versatilidad de géneros (≥6.5) + 25% Índice de autoría (créditos Writer/Screenplay/Story).
Cultural Legacy10%Escala logarítmica sobre los Top 5 títulos más votados (multiplicador clásico pre-1990 hasta 1.12×).

Peak (70%) + Consistencia (30%) y Compresión Élite

Rating_Final = 0.60 * IMDb + 0.40 * TMDb (rating directo; sin suavizado por votos) PeakScore = mean(Top 4 Rating_Final, max 1 obra por franquicia o serie) ConsistencyCount = clamp(round(6 + ((eligible.length - 6) / 24) * 6), 6, 12) ConsistencyScore = mean(Top ConsistencyCount Rating_Final, max 2 por franquicia) Quality = 0.70 * clamp(((PeakScore - 6.0) / 2.35) * 100) + 0.30 * clamp(((ConsistencyScore - 6.0) / 2.35) * 100) // Mezcla asimétrica y compresión superior (> 88): score = (awards >= baseScore) ? 0.75 * baseScore + 0.25 * awards : 0.95 * baseScore + 0.05 * awards if (score > 88) { r = (score - 88) / 12 score = 88 + 7.5 * (ln(1 + 1.5 * r) / ln(2.5)) }

Umbrales de TV y Límite de Franquicia / Serie (Directors v5)

  • Series regulares: Requiere job === "Director" y episode_count >= 2.
  • Miniseries (type === "Miniseries"): Requiere episode_count >= 1.
  • Agrupación por serie / franquicia: Todas las temporadas o episodios dirigidos de una misma serie se agrupan bajo el identificador único tv:{series_id}, garantizando que una sola serie cuente como una única obra y no monopolice el Top 4 Peak ni la ventana de consistencia.
  • Exclusiones no ficticias: Se descartan los géneros 99 (Documentary), 10763 (News), 10764 (Reality), 10767 (Talk Show) y 10770 (TV Movie).

Versatilidad de Géneros (75%) e Índice de Autoría (25%)

GenreVersatility = clamp((distinctGenreGroups(rating >= 6.5) / 6) * 100) AuthorshipIndex = (obrasConCréditoGuion / totalObrasVálidas) * 100 PillarScore = clamp(0.75 * GenreVersatility + 0.25 * AuthorshipIndex)
